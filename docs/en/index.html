Covi and the island

Choose Covi skins, accessories, click reactions and expanded idle gaze behavior in Cove Studio. Classic remains the baseline look, with Aurora, Midnight and Ember included.

Local context

Codex lifecycle, timers, music, weather, time-of-day and audio output context are presented with compact, prioritized reactions.

Covi Workshop

Create local Covi looks, import and export `.coviskin` files, and keep custom definitions separate from settings. `.coviskin` files cannot include code or remote URLs.

Local-first

No product analytics, telemetry service or account system. Weather and optional artwork lookup are the only network features in this preview.
